
# RGB Colour Mixer 🎨

## Project Description
RGB Colour Mixer is an interactive web application built
with Python and Streamlit. It allows users to mix Red,
Green, and Blue colour channels to create different colours.

## Features
- Interactive RGB sliders
- Live colour preview
- RGB and HEX colour codes
- Preset colours
- Reset button
- Simple and user-friendly interface

## Technologies Used
- Python
- Streamlit
- HTML and CSS

## Installation

1. Clone this repository:

   git clone https://github.com/YOUR-USERNAME/rgb-colour-mixer.git

2. Open the project folder:

   cd rgb-colour-mixer

3. Install the required library:

   pip install -r requirements.txt

4. Run the application:

   streamlit run app.py

## Deployment
Upload these files to GitHub and deploy the repository
using Streamlit Community Cloud.
